常见误区

写法或想法 实际情况 更稳妥的处理
text[0] = "A" 字符串不可变，不能通过索引改写 创建新字符串，例如 "A" + text[1:]
b = a 就是复制列表 两个名称指向同一个列表 使用 a.copy() 创建浅拷贝
a[1:3] 包含索引 3 切片右端不包含 把结束位置理解为“边界”
3 / 2 得到整数 / 返回浮点数 1.5 需要整除时使用 //
